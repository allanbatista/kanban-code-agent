# Layout App

Interface web do swarm PoC.

## Theme

- Dark elegant palette: deep navy/graphite background, periwinkle primary, status colors tonais.
- Superfícies com blur leve, bordas suaves e contraste consistente em kanban, projects, settings e workflow.

## Development

```bash
npm install
npm run dev
```

## Build and validation

```bash
npm run build
npm run lint
```

## Main routes

- `/` Kanban Board
- `/projects` Projects Grid
- `/projects/:id` Project Detail
- `/settings` Settings
